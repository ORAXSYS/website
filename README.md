# ORAXSYS public website

This repository hosts the public website at https://oraxsys.com/.

- Website development: [gilshl/orqaxis-website](https://github.com/gilshl/orqaxis-website) (private; Pages disabled).
- Production website: [ORAXSYS/website](https://github.com/ORAXSYS/website) (public; GitHub Pages enabled).
- Application source remains in its separate development repository.

Website changes in the development repository do not publish automatically. Promote a reviewed snapshot in one commit, record its source commit and file hashes in `publication.json`, and preserve this repository's `CNAME` and `.nojekyll` files.

See [docs/deployment.md](docs/deployment.md) for the current hosting configuration and promotion process.
